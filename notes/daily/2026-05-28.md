## Work

### Dezibel Beat Editor

Hardened the editor for production use across three fronts. Added a service worker that caches the HTML file and Google Fonts so the editor survives localhost server restarts — network-first for the editor, cache-first for fonts. Built a toast severity system with three tiers: default (grey, auto-dismiss), warn (yellow, 6s), and error (red, persists until manual dismiss) — all data-loss warnings (word count drops, beat count drops, disk write failures) now use error-level toasts that stay on screen. Added a keyboard shortcuts help modal triggered by `?` that's context-aware (shows ME shortcuts when ME is open). Also fixed four bugs found via adversarial scenario tracing: write-lock false positive triggering the block overlay, missing FileLink permission gates on `meStartEdit` and `openProse`, `saveState` metadata leak on localStorage quota error, and `dezibel-emergency-wordcount` missing from the 24h cleanup list. Codified eight engineering rules into CLAUDE.md to prevent recurring bug introduction.
